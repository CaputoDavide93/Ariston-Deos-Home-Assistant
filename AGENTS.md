## Rules that apply to every change

- **Documentation never lies.** Every command, flag, feature, count and badge must be true of the code. Verify before writing; delete what you can't verify. No hand-typed counts that can drift.
- **Commits:** conventional (`fix:`, `feat:`, `docs:`, `refactor:`, `ci:`, `chore:`), authored by the repo owner. No co-author trailers, session ids or "generated by" lines in commits, PRs, issues or comments.
- **Never** force-push the default branch, commit secrets, or change runtime identifiers (env var names, entity ids, the integration domain, public URLs) as a side effect.
- Run the repo's own checks before and after; anything green before stays green.

## This repo: Ariston Deos

A Home Assistant custom integration, displayed as **Ariston Deos**, for an Ariston Deos
16S NET dehumidifier, through the Midea cloud behind the Ariston Clima app.

- **The domain `ariston_deos` must not change.** Entity ids and config entries hang off it.
- **Never commit credentials.** No Ariston Clima email or password, token, key, session
  id or device id, in code, tests, fixtures, logs or docs. Test fixtures use obviously
  fake values. `*.keys` and `.env` are git-ignored; keep them so.
- **Region matters: EU or US.** The library offers "Ariston Clima EU"
  (`mapp-eu.appsmb.com`) and "Ariston Clima" (`mapp.appsmb.com`, US). HA Core Midea's
  token call fails on the US server with code 9999. Whether the EU server holds the
  account is the first thing to settle, with `scripts/probe.py`.
- **Verified:** the library's API surface and the udp id derivation, read from its source
  (`midea-beautiful-air` 0.10.7); the probe's pure helpers, by unit tests; the probe's
  udp id matches the library's own function.
- **Not verified:** any call against the live cloud, from the probe or the integration;
  that the Deos 16S NET answers the library's dehumidifier status frame; what the mode
  numbers mean on this model. Say "untested against the live cloud" until that changes.
- **The probe is read-only.** It must never send a set command, and never print, log or
  write a credential, token or key value (lengths and a mode-600 file via `--save-keys` only).
- The integration pins `midea-beautiful-air` in `manifest.json`; bump it deliberately.
